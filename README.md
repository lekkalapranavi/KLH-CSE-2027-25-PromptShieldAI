### Abstract
PromptShield AI aims to identify and reduce prompt injection vulnerabilities in an LLM-powered campus chatbot. The project examines direct prompt injection, indirect prompt injection through untrusted content, and jailbreak attempts. It proposes layered defense mechanisms such as input screening, separation of trusted instructions from untrusted content, access checks, and output validation. The prototype will compare chatbot behavior before and after applying defenses and record the results through a simple dashboard. The goal is to demonstrate practical security testing and evaluate the effectiveness and limitations of the implemented defenses.

### Project Objectives
- Identify common prompt injection attack patterns.
- Develop a controlled campus chatbot prototype.
- Implement layered prompt security mechanisms.
- Evaluate chatbot responses before and after defense implementation.
- Record and visualize security testing results.
